# Local API (v1)

> **Undo docs** · [Index](README.md) · [Installation](INSTALLATION.md) · [CLI](CLI.md) · [Recovery](RECOVERY.md) · [Troubleshooting](TROUBLESHOOTING.md) · [Development](DEVELOPMENT.md) · [Architecture](ARCHITECTURE.md) · [Storage](STORAGE.md) · **API**

The JSON API the daemon serves for the CLI, the dashboard and the app. Use it from your own
scripts on the same machine.

The daemon serves a JSON API at `http://127.0.0.1:<port>/api/v1` (default port 47821; if busy a
random port is used). The actual address is in `<data>/daemon.json`.

* **Binding:** loopback only. `api.host` must be a loopback address unless `api.allow_remote` is
  explicitly enabled (not recommended).
* **Authentication:** every endpoint except `GET /ping` requires
  `Authorization: Bearer <token>` (or `X-Undo-Token`). The token is generated by `undo init`, stored in
  `<data>/api_token` with owner-only permissions and compared in constant time.
* **Errors:** `{"error": {"code": "...", "message": "...", "details": {}}}` with HTTP status:
  401 `unauthorized`, 404 `not_found`, 409 `conflict` / `not_initialized`, 422 `invalid_input` /
  `path_outside_root` / `unsafe_path`, 423 `locked`, 500 `storage_integrity` / `internal_error`.
* **Schemas:** request bodies are in `undo_core/api/schemas`, responses are the models in
  `undo_core/domain.py`. `make docs` writes the OpenAPI document to
  [API_OPENAPI.json](API_OPENAPI.json).
* **Interactive docs:** open `http://127.0.0.1:47821/api/v1/docs` in a browser, click
  **Authorize**, paste the token (without `Bearer`) and use *Try it out*. Requests really run:
  keep `dry_run: true` on restores until you mean it. `http://127.0.0.1:47821/` itself returns
  `{"detail":"Not Found"}`, because there is no page at the root.
* **Token:** `cat ~/.local/share/undo/api_token` (Linux) or
  `Get-Content $env:LOCALAPPDATA\Undo\api_token` (PowerShell). Created by `undo init`, never
  expires. To replace it, delete the file and run `undo restart`.

## Endpoints

| Method & path | Body / query | Returns |
|---|---|---|
| `GET /ping` | (no auth) | `{app, version, api_version}` |
| `GET /health` | | `HealthInfo` (pid, uptime, watchers, queue, captures, jobs, recovery, errors) |
| `GET /status` | | `StatusInfo` |
| `GET /doctor` | | `DoctorCheck[]` |
| `POST /daemon/shutdown` | | `{status}` |
| `GET /roots` | | `RootInfo[]` |
| `POST /roots` | `{path, scan}` | `AddRootResult` (201) |
| `GET /roots/{id}` · `PATCH /roots/{id}` | `{enabled}` | `RootInfo` |
| `DELETE /roots/{id}?purge=bool` | | `RootInfo` |
| `POST /scan` | `{target?, deep}` | `ReconcileReport[]` |
| `GET /files` | `root_id, query, include_deleted, deleted_only, prefix, limit, offset` | `FilePage` |
| `GET /files/{id}` · `GET /files/resolve?path=` | | `FileInfo` |
| `GET /files/deleted` | `root_id, path, limit` | `FileInfo[]` |
| `GET /files/skipped` | `root_id, limit` | `SkipInfo[]` |
| `GET /files/search?query=` | `limit` | `SearchHit[]` |
| `GET /history/files/{file_id}` · `GET /history/path?path=` | `limit` | `FileHistory` |
| `GET /history/log` | `limit, root_id, since` | `VersionInfo[]` |
| `GET /versions/{id}` | | `VersionDetail` |
| `GET /versions/{id}/preview` | `max_bytes` | `VersionContent` |
| `GET /versions/{id}/content` | | raw bytes (streamed) |
| `GET /versions/diff?a=&b=` | | `VersionDiff`: `hunks` (side-by-side rows with changed-character spans), unified `diff` text, `added`, `removed`, `note` |
| `POST /history/forget` | `{path, before?, dry_run}` | `ForgetResult` |
| `POST /versions/delete` | `{version_ids, dry_run}` | `ForgetResult` |
| `POST /restore` | `{path, version_id?, at?, before_version_id?, destination?, overwrite, dry_run}` | `RestoreResult` |
| `POST /restore/version` | `{version_id, destination?, overwrite, dry_run}` | `RestoreResult` |
| `POST /restore/recover` | `{path, destination?, overwrite, dry_run}` | `RestoreResult` |
| `GET /snapshots?root=` · `POST /snapshots` | `{name, root?, description?, scan}` | `SnapshotInfo[]` / `SnapshotInfo` |
| `GET /snapshots/{ref}` | id or name | `SnapshotDetail` |
| `GET /snapshots/{a}/diff/{b}` | | `SnapshotDiff` |
| `POST /snapshots/{ref}/restore` | `{destination?, prefix, overwrite, dry_run}` | `RestoreResult` |
| `DELETE /snapshots/{ref}` | | `SnapshotInfo` |
| `GET /storage/stats` | | `StorageStats` |
| `POST /storage/verify` | `{full, repair}` | `VerifyReport` |
| `POST /storage/gc` | `{dry_run}` | `GCReport` |
| `POST /storage/retention` | `{dry_run}` | `RetentionReport` |
| `GET /settings` | | settings object (+ `_info`) |
| `PUT /settings` | `{key, value}` | settings |
| `PATCH /settings` | partial settings object | settings |
| `GET /exclusions?root=` | | `ExclusionInfo[]` |
| `POST /exclusions` · `POST /exclusions/remove` | `{pattern, root?}` | `ExclusionInfo` |

All timestamps are ISO-8601 in UTC. Long operations (scan, verify, snapshot creation) run
synchronously; clients should use generous timeouts.

## Example

```sh
TOKEN=$(cat ~/.local/share/undo/api_token)
PORT=$(python -c "import json;print(json.load(open('$HOME/.local/share/undo/daemon.json'))['port'])")
curl -s -H "Authorization: Bearer $TOKEN" http://127.0.0.1:$PORT/api/v1/status
curl -s -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
     -d '{"path":"/home/me/notes.txt","at":"2h","dry_run":true}' http://127.0.0.1:$PORT/api/v1/restore
```
